
Core features:
1. A smart calendar. The user should be able to note down events, all the things they need to do, just like google calendar. But the interesting thing will be a chat box right above the caldendar, where a AI chatbot lives, and you can tell it to schedule for you.
For example, you can say "Dinner with mom 7pm tonight" and it will schedule it for you immediately. Or you can say "Meeting at 3pm tomorrow", done. Quick and efficient.

2. A task manager that sync with the caldendar. It will act like a todo app, with tasks from the calendar that you have scheduled, along with checkboxes and snooze buttons, where you can snooze the tasks, and have the calendar sync up to it.
